我的 Neovim 配置

发布日期: 2023-07-03更新日期: 2023-07-19

在这里记录一下我的 nvim 配置。

持续更新中...

快捷键配置

按键符号采用 nvim 内的示例，如A表示alt、C表示ctrl、<CR>表示回车等。 详细内容参考:help keycodes。

nvim 快捷键

这些是 nvim 自身的快捷键，而不是插件相关的快捷键。

模式按键意义
n<A-t>关闭标签页
nt下一个标签页
n<C-t>新建标签页
n<S-t>上一个标签页
n<C-j>向上滚动，映射为<C-E><C-E>
n<C-k>向下滚动，映射为<C-Y><C-Y>
n<TAB>下/右窗口，映射为<C-W>w
n<S-TAB>上/左窗口，映射为<C-W>W

gitsigns 快捷键

gitsigns 是在文件内对 git 记录进行快速操作的插件， 可以快速地重置、保存和查看更改记录[^Git 记录]

[^Git 记录]: 在 Git 中，修改过的记录称为 hunk，我习惯称为 chunk。此外我还习惯称之为记录块，简称记录。

快捷键大部分在 normal 模式下使用。

按键意义
]c下一个记录
[c上一个记录
gsu撤销保存记录
gss暂存记录
gsr重置记录
gsS暂存缓冲区所有记录
gsR重置缓冲区所有记录
gsp预览修改
gsd相当于git diff
gsD相当于git diff HEAD
gst查看/隐藏删除的记录

这个快捷键使用的模式比较特殊。

模式按键意义
oxgsc选择整个记录块（GitSaga Select Chunk）

LSP 快捷键

LSP 快捷键大部分处于 normal 模式。一些功能会使用到光标处的单词作为符号。

按键意义
<leader>el显示行诊断
<leader>ec显示光标处诊断
<leader>ea显示缓冲区诊断
<leader>fa格式化代码
<leader>rn符号重命名，可在 visual 模式使用
<leader>lr查看符号引用
<leader>li查看实现
<leader>ol大纲
]e下一个问题诊断
[e上一个问题诊断
<M-CR>显示代码建议，可在 visual 模式使用
gc跳转到声明
gd跳转到定义
gt跳转到类型定义
K查看文档

Lspsaga 快捷键

Lspsaga 为 neovim 内置的 LSP 提供了更友好的界面， 因此在 Lspsaga 中配置的快捷键与 LSP 的基本相同，并会覆盖 LSP 的快捷键。 在这里列出 Lspsaga 专有的快捷键。

按键意义
<leader>ls列出符号的所有定义、引用与实现
<leader>pd在悬浮窗口查看符号定义
<leader>pt在悬浮窗口查看类型定义
]E下一个错误（忽略警告）
[E上一个错误（忽略警告）
<leader>ci列出所有调用符号的位置
<leader>co列出符号调用的方法

Lspsaga 在预览窗口的快捷键有些混乱，大部分快捷键作用是相同的， 但有个别在不同类型的窗口1内不同， 加上个人习惯修改了部分按键，这里只列个大概。

  • <C-d>、<C-u>：窗口内容滚动。对应down和up的意思。
  • <C-t>：跳出窗口。
  • q、<ESC>、<C-c>：这些基本都有退出或取消操作的意思。
  • g：这个大部分情况下是跳转。
  • o：这个是展示预览或者编辑的意思，如果只是展示则不会跳转，此外还有打开折叠栏的意思。
  • <CR>：表示执行、跳转等意思。
  • v、x、t、r：这些都是新建窗口进行下一步操作。 分别对应vsplit、split、tabedit、tabnew。

o指令与<CR>有功能上的重复，但还是有一些区别。 如在大纲窗口中，o与<CR>都表现为在编辑区域打开并跳转到函数所在位置。 但在诊断窗口中，o被配置为展开折叠栏，而<CR>被配置为执行 Code Action。

Floaterm 快捷键

这是个悬浮终端的插件。

模式按键意义
nt<F12>显示/隐藏悬浮终端
nt<leader>f12同上，但在没有 Fn 键的时候使用

nvim-tree 快捷键

nvim-tree 在自己的窗口中有自己的快捷键，使用:help nvim-tree-mapping-default查看。

模式按键意义
niv<F2>打开/隐藏文件树
niv<leader>f2同上，但在没有 Fn 键的时候使用

Telescope 快捷键

快捷键都处于 normal 模式使用。

按键意义
<F3>查找文件，同时可用于关闭窗口
<leader>F3同上，但在没有 Fn 键的时候使用
<leader>clp查看 register 内容
<leader>ch查看历史命令
<leader>sh查看搜索历史

Nerdcommter 快捷键

用于快速注释。

模式按键意义
n<leader>ca切换注释风格，如 C 的//和/* */
nx<leader>cc注释/取消注释
nx<leader>cs块注释
nx<leader>cu取消注释
