将 init.vim 迁移至 init.lua

发布日期: 2023-01-12更新日期: 2023-01-14

本文是根据 neovim 手册写的一些笔记，是我在迁移时遇到的一些问题，记录下来方便回顾。 详细的内容可在 nvim 中使用命令:help lua-guide进行查看。

迁移变量

参考手册 :help lua-guide-variables

首先的第一种类型变量，使用let指令赋值，一般可被分为以下几种：

  • 全局变量（Global)，在 vim 中以g:开头
  • 缓存区变量（Buffer-socped），在 vim 中以b:开头
  • 窗口变量（window-socped），在 vim 中以w:开头
  • 标签页变量（tabpage-socped），在 vim 中以t:开头
  • 普通变量，在 vim 中以v:开头
  • 环境变量，如$HOME

在 lua 中可以使用 vim 模块轻松的访问或设置这些变量。 如let g:airline_theme='owo'，在 lua 中可以这样设定vim.g.airline_theme='owo'， 类似的，可以使用vim.b.foo、vim.w.foo、vim.t.foo、vim.v.foo、foo.env 对其他类型的变量进行访问与设置。 没有前缀的变量应该在vim.g中。

参考手册 :help lua-guide-options

还有一种类型的变量，说是变量，但实际上是 vim 内置的选项， 在 vim 中使用set相关的指令进行设置。

在 lua 中，使用vim.o、vim.go、vim.bo、vim.wo对这些变量进行访问与设置。 在我的迁移过程中使用的比较少，请参考手册。

迁移按键映射

参考手册:help lua-guide-mappings

在 lua 中使用vim.keymap.set()函数进行映射，详细请参考手册。

在迁移 coc.nvim 插件时，由于 coc 的 Github 主页上的 README 中写的配置没有更新1， 于是要自己去看手册找函数什么的。有一个例子是在 init.vim 的配置中， 有个coc#pum#visable()函数，新的调用方式是pumvisable()这样子的。 而在 lua 中则应该这样子调用：vim.fn.pumvisable()， 并且这个函数的返回值似乎返回的是数字，因此在 vim 中的配置

inoremap <silent><expr> <TAB>
    \ pumvisable() ? "\<C-n>" :
    \ <SID>check_back_space() ? "\<TAB>" :
    \ coc#refresh()

在 lua 中则可以这样子配置

local opts = {silent = true, noremap = true, expr = true}
vim.keymap.set("i", "<TAB>", "pumvisable() ? '\<C-n>' : <SID>check_back_space() ? '\<TAB>' : coc#refresh()", opts)
-- 这个实际上是直接使用了 vim 的配置，大部分的配置都可以像这样子进行迁移

-- 但我喜欢直接使用 lua 函数，就像下面这样
vim.keymap.set("i", "<TAB>", function()
    if vim.fn.pumvisable() == 1 then
        return "<C-n>"
    elseif check_back_space() then
        return "<TAB>"
    end
end, opts)

这个例子可以在:help coc-completion中找到，用到的快捷键，如<C-n>， 可以在:help coc-list-mappings中找到

其实大部分的映射可以直接使用，剩下的需要修改的也基本与上述例子相同。

迁移 vim 命令

参考手册:help lua-guide-vim-commands

vim 命令是指在命令模式中使用的指令，就是跟在:后面的，比如:highlight、:syntax等， 这些指令可以通过vim.cmd.highlight、vim.cmd.syntax来访问。

但有个令人困惑的问题，在创建 NERDTree 的一个 autocmd 时， 有一个silent NERDTreeMirror的命令， 直接转换成vim.cmd.silent("NERDTreeMirror")会失败， 使用vim.cmd("silent NERDTreeMirror")则可以正常使用。

迁移函数

参考手册:help lua-guide-vim-functions

函数的迁移比较复杂，请参考手册。

迁移插件

这里只记录如何在 lua 中使用vim-plug作为插件管理器。
我使用的方法如下：

vim.fn['plug#begin']()
vim.cmd("Plug 'example/plug'")  -- 注意 Plug 方法后面跟的插件需要带单引号 `'`，
                                -- 因此外围函数使用双引号 `"`。
vim.fn['plug#end']()

实际上可以封装成一个函数，如Plug('example/plug')， 这样子看起来挺像原生的 vim-plug 的方法。owo

其他

最后为了能格式化 lua 的配置文件，使用sumneko/lua-language-server 作为 LSP 服务器，在参考了coc 的配置例子后， 使用的配置如下：

{
  "languageserver": {
    "lua": {
      "command": "lua-language-server",
      "args": [],
      "filetypes": ["lua"]
    }
  }
}

注：我是从 ArchLinux 软件源中安装的，因此lua-language-server可直接调用 =w=
