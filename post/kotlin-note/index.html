Kotlin 简介

Kotlin 由 JetBrains 开发，2017 年被 Google 宣布为 Android 官方支持语言，2019 年起成为 Android 首选语言。它的几个核心卖点：

特性 说明
简洁 类型推断、属性语法、单表达式函数、数据类，样板代码远少于 Java
空安全 类型系统区分「可空」与「不可空」，把空指针问题提前到编译期
函数式 一等公民的 lambda、高阶函数、不可变集合、链式集合操作
完全兼容 Java 可调用 Java 代码，也可被 Java 调用；直接跑在 JVM 上
多平台 Kotlin/JVM、Kotlin/JS、Kotlin/Native、Kotlin/Wasm（KMP 共享业务逻辑）
协程 语言级异步方案，用同步写法写异步代码

Kotlin 的设计目标是「更安全的 Java」，所以它不是脚本玩具语言——它编译成 JVM 字节码，性能与 Java 基本一致（内联函数等特性甚至更好）。

环境与第一个程序

准备

  • JDK 17 或更高版本（推荐 21 LTS）
  • 任选一种开发方式：
    • IntelliJ IDEA（社区版免费，对 Kotlin 支持最好，推荐）
    • 命令行：kotlinc 编译器
    • Gradle：正式项目用
    • 在线试用：https://play.kotlinlang.org（无需安装，适合验证小片段）

验证 Java

java -version

看到类似 openjdk version "21" 即可。若没有，请先安装 JDK（Arch：sudo pacman -S jdk-openjdk；Ubuntu：sudo apt install openjdk-21-jdk）。

第一个程序

新建文件 hello.kt（扩展名必须是 .kt）：

fun main() {
    println("Hello, Kotlin!")
}

运行方式（三选一）：

# 方式一：直接运行（需要 kotlin 命令，适合小脚本）
kotlin hello.kt

# 方式二：编译成 jar 再运行
kotlinc hello.kt -include-runtime -d hello.jar
java -jar hello.jar

# 方式三：在 IntelliJ IDEA 里点击 main 函数左侧的绿色三角

说明：Kotlin 没有「类必须包含 main」的限制，main 可以写在文件顶层。带参数的写法是 fun main(args: Array<String>)，但在 1.3+ 中通常不再需要写参数。

关于文件

  • 一个 .kt 文件可以包含多个类、函数，文件名不必与类名一致。
  • 顶层函数编译后会生成一个名为 文件名Kt 的类（如 hello.kt → HelloKt），这在和 Java 互操作时会用到（见「与 Java 互操作」）。

变量、常量与基本类型

val 与 var

val name = "Kotlin"   // 只读（等价于 Java 的 final），推荐默认使用
var count = 0         // 可变
count = 1             // OK
// name = "Java"      // 编译错误：Val cannot be reassigned

约定：优先用 val，只在确实需要修改时才用 var。这让代码更容易推理。

类型声明与类型推断

val age: Int = 18          // 显式声明
val city = "Beijing"       // 推断为 String
val ratio = 0.75           // 推断为 Double
val big: Long = 10_000_000_000L   // 超出 Int 范围必须加 L

Kotlin 是静态强类型语言，所有类型在编译期确定，但大部分时候可以省略类型标注。

基本类型

类型 说明 字面量示例
Byte 8 位整数 1
Short 16 位整数 1
Int 32 位整数（默认整数类型） 42
Long 64 位整数 42L
Float 32 位浮点 3.14f
Double 64 位浮点（默认小数类型） 3.14
Boolean 布尔 true
Char 单个字符 'A'
String 字符串 "abc"

进制与可读性写法：

val hex = 0xFF            // 255
val bin = 0b1010          // 10
val million = 1_000_000   // 下划线只是可读性分隔符

没有隐式宽化转换，这一点和 Java 不同：

val i: Int = 10
// val l: Long = i        // 编译错误！
val l: Long = i.toLong()  // 必须显式转换
val d: Double = i.toDouble()
val s: String = i.toString()
val parsed: Int = "123".toInt()      // 失败会抛 NumberFormatException
val safe: Int? = "123".toIntOrNull() // 失败返回 null（更安全）

字符串与模板

val name = "Kotlin"
val version = 2

println("Hello, $name!")                  // 简单变量
println("版本: ${version + 1}")            // 表达式需要花括号
println("长度: ${name.length}")
println("首字母大写: ${name.uppercase()}")

val multi = """
    第一行
    第二行
""".trimIndent()
println(multi)

多行字符串（raw string）里的内容不做转义，非常适合写 JSON、SQL、正则：

val regex = """\d{3}-\d{4}""".toRegex()

字符串常用操作：length、isEmpty()、substring()、split()、trim()、replace()、contains()、startsWith()、padStart()、repeat()。

注意：Kotlin 的 == 比较的是内容（相当于 Java 的 equals），=== 才比较引用。字符串比较永远用 ==。

控制流

if 是表达式

Kotlin 中 if 有返回值，因此不需要 Java 的三元运算符 ? :：

val a = 10
val b = 20

val max = if (a > b) a else b
println("max = $max")

// 代码块形式，最后一个表达式的值就是返回值
val desc = if (a % 2 == 0) {
    println("偶数分支")
    "偶数"
} else {
    "奇数"
}

when：更强的 switch

fun describe(x: Any): String = when (x) {
    0 -> "零"
    in 1..9 -> "个位数"
    is String -> "字符串，长度 ${x.length}"
    is List<*> -> "列表，大小 ${x.size}"
    else -> "其他"
}

when 的特性：

  • 支持常量、区间、is 类型判断、任意布尔表达式；
  • 不需要 break，每个分支自带终止；
  • 作为表达式时必须穷尽所有情况（else 或覆盖全部子类型，见 sealed class）；
  • 没有参数的 when 可以替代 if-else if 链：
val score = 85
val grade = when {
    score >= 90 -> "A"
    score >= 80 -> "B"
    score >= 60 -> "C"
    else -> "D"
}

循环

// for-in：最常见
for (i in 1..5) print("$i ")        // 1 2 3 4 5
for (i in 1 until 5) print("$i ")   // 1 2 3 4（左闭右开）
for (i in 5 downTo 1 step 2) print("$i ")  // 5 3 1

val fruits = listOf("苹果", "香蕉", "橙子")
for (f in fruits) println(f)

// 带下标
for ((index, value) in fruits.withIndex()) {
    println("$index: $value")
}

// 遍历 map
val ages = mapOf("Tom" to 18, "Ann" to 20)
for ((name, age) in ages) println("$name -> $age")

// while / do-while
var n = 3
while (n > 0) { println(n); n-- }

do {
    println("至少执行一次")
} while (false)

// 固定次数
repeat(3) { i -> println("第 ${i + 1} 次") }

区间（Range）

val r1 = 1..10        // IntRange，闭区间
val r2 = 1 until 10   // 不含 10
val r3 = 'a'..'z'
println(5 in r1)      // true
println(r1.first)     // 1
println(r1.last)      // 10
println((1..10).step(3).toList())  // [1, 4, 7, 10]

标签与跳出

outer@ for (i in 1..3) {
    for (j in 1..3) {
        if (i * j == 6) break@outer   // 直接跳出外层循环
        print("$i*$j ")
    }
}

lambda 里的 return 默认返回所在函数，如果只想跳出 lambda，也要用标签：return@forEach。

函数

基本形式

fun add(a: Int, b: Int): Int {
    return a + b
}

// 单表达式函数：返回类型可省略（能推断时）
fun multiply(a: Int, b: Int) = a * b

// 无返回值（Unit 可省略）
fun greet(name: String) {
    println("Hi, $name")
}

// 显式 Unit
fun log(msg: String): Unit = println(msg)

默认参数与命名参数

fun connect(host: String = "localhost", port: Int = 8080, secure: Boolean = false) {
    println("$host:$port secure=$secure")
}

connect()                                // 全用默认值
connect(port = 9090)                     // 命名参数，跳过前面的参数
connect("example.com", secure = true)    // 混合使用

这可以替代大量的方法重载。

可变参数（vararg）

fun sum(vararg numbers: Int): Int = numbers.sum()

println(sum(1, 2, 3))
println(sum(*intArrayOf(4, 5, 6)))   // 用 * 展开数组

局部函数与嵌套

fun validate(input: String): Boolean {
    fun isNotBlank() = input.isNotBlank()
    fun isShort() = input.length <= 10
    return isNotBlank() && isShort()
}

扩展函数

可以在不修改原类的前提下添加方法（编译期静态解析，本质是静态函数）：

fun String.addExclamation(): String = this + "!"

fun String.shout() = uppercase() + "!!!"

println("hello".addExclamation())  // hello!
println("hello".shout())           // HELLO!!!

// 扩展属性（不能有 backing field，除非用 getter 计算）
val String.lastChar: Char
    get() = this[length - 1]

// 可空接收者：用 ?. 调用，内部 this 可能为 null
fun String?.orDefault(): String = this ?: "(空)"

扩展函数不能访问类的 private 成员，也不会被真正「覆盖」（多态对扩展函数无效，取决于变量的静态类型）。

中缀函数（infix）

infix fun Int.max(other: Int): Int = if (this > other) this else other

println(3 max 10)   // 10

to 就是标准库里的中缀函数："key" to "value"。

高阶函数与 lambda

函数可以作为参数或返回值：

// 接收 (Int) -> Int 类型的函数
fun applyTwice(x: Int, f: (Int) -> Int): Int = f(f(x))

println(applyTwice(3) { it * 2 })   // 12
println(applyTwice(3, ::square))    // 函数引用

fun square(x: Int) = x * x

lambda 语法要点：

val sum: (Int, Int) -> Int = { a, b -> a + b }   // 显式类型
val double: (Int) -> Int = { it * 2 }            // 单参数可用 it

// 尾随 lambda：最后一个参数是函数时可以提到括号外
listOf(1, 2, 3).forEach { println(it) }

// 多参数时建议命名，提升可读性
val add: (Int, Int) -> Int = { x, y -> x + y }

尾递归优化

tailrec fun factorial(n: Int, acc: Long = 1L): Long =
    if (n <= 1) acc else factorial(n - 1, acc * n)

tailrec 会编译成循环，避免栈溢出（要求递归调用必须是最后一步操作）。

内联与具体化类型参数

inline 把函数体直接展开到调用处，配合 reified 可以在运行时拿到泛型类型：

inline fun <reified T> Any?.isInstanceOf(): Boolean = this is T

println("abc".isInstanceOf<String>())  // true
println(123.isInstanceOf<String>())    // false

标准库的 filterIsInstance<T>()、requireNotNull<T>() 都基于它实现。

空安全

这是 Kotlin 相对 Java 最大的改进。类型分为 String（不可空）和 String?（可空），把 null 当作类型的一部分。

var name: String = "Kotlin"
// name = null          // 编译错误，从源头禁止
var nickname: String? = null   // 允许为 null

安全调用 ?.

val len: Int? = nickname?.length       // nickname 为 null 时不报错，返回 null
val upper: String? = nickname?.uppercase()

// 链式调用：任一处为 null 就整体为 null
val city: String? = user?.address?.city

埃尔维斯运算符 ?:

val display = nickname ?: "匿名用户"          // 左边为 null 时用右边
val length = nickname?.length ?: 0

// 提前返回的惯用法
fun process(input: String?) {
    val text = input ?: return
    println(text.length)   // 此处 text 已智能转换为非空 String
}

非空断言 !!

val forced: String = nickname!!.uppercase()   // 为 null 时抛 NullPointerException

!! 是「我知道它一定不为 null」的声明。能不用就不用，它等于放弃了空安全的全部收益。代码里出现大量 !! 通常说明类型设计有问题。

智能转换（smart cast）

fun printLength(s: String?) {
    if (s != null) {
        println(s.length)   // 编译器知道这里 s 不是 null，无需 !!
    }
}

fun handle(x: Any) {
    if (x is String) {
        println(x.length)   // 自动转换为 String
    }
}

智能转换对 var 属性、自定义 getter 不生效（因为值可能变化），此时用局部变量接一下即可： val s = this.property ?: return。

as? 安全转换、lateinit、by lazy

val obj: Any = "hello"
val s: String? = obj as? String    // 失败返回 null，而不是抛 ClassCastException

// lateinit：延迟初始化（只能是 var，不能是基本类型，不能用于可空类型）
class Service {
    lateinit var config: String

    fun init() { config = "loaded" }

    fun check() {
        if (::config.isInitialized) println(config)
    }
}

// by lazy：首次访问时计算，之后复用（线程安全，默认 SYNCHRONIZED）
class Repo {
    val data: List<String> by lazy {
        println("只计算一次")
        loadFromNetwork()
    }
    private fun loadFromNetwork(): List<String> = listOf("a", "b")
}

平台类型

调用 Java 代码时，Java 的 String 在 Kotlin 眼里是 String!（平台类型），编译器不知道它是否可空，不会强制空检查。这类地方要自己小心，或者直接标注为可空类型：

val s: String? = javaMethod()   // 主动按可空处理

类与对象

类、主构造函数、init、次构造函数

class Person(val name: String, var age: Int = 0) {   // 主构造函数，val/var 直接声明属性
    init {
        require(age >= 0) { "年龄不能为负" }          // 初始化块，可写多条
    }

    // 次构造函数必须（间接）委托给主构造函数
    constructor(name: String) : this(name, 0)

    fun birthday() {
        age++
    }
}

val p = Person("Tom", 20)
p.birthday()
println("${p.name} 现在 ${p.age} 岁")

如果主构造函数不带 val/var，参数只是构造参数，不是属性：

class User(name: String) {          // name 只在初始化阶段可用
    val display = name.trim()
}

属性与自定义访问器

class Temperature {
    var celsius: Double = 0.0

    val fahrenheit: Double                  // 计算属性，无 backing field
        get() = celsius * 9 / 5 + 32

    var kelvin: Double
        get() = celsius + 273.15
        set(value) {
            require(value >= 0) { "不能低于绝对零度" }
            celsius = value - 273.15
        }
}

继承与覆写

Kotlin 的类默认是 final 的，必须显式加 open 才能被继承；方法同理：

open class Animal(val name: String) {
    open fun sound() = "..."

    fun sleep() = println("$name 睡觉")   // 默认 final，不能覆写
}

class Dog(name: String) : Animal(name) {
    override fun sound() = "汪汪"
}

val d: Animal = Dog("旺财")
println(d.sound())      // 汪汪（多态生效）

覆写规则：

  • 覆写父类成员必须写 override（不能省略，避免误覆盖）；
  • 用 override 修饰的成员默认仍是 open，不想再被继承就写 final override；
  • 调用父类实现用 super.sound()。

抽象类与接口

abstract class Shape {
    abstract fun area(): Double          // 抽象方法，无实现
    open fun describe() = "面积 = ${area()}"
}

interface Clickable {
    fun click()                          // 抽象方法
    fun showOff() = println("我是可点击的")  // 带默认实现
}

interface Focusable {
    fun showOff() = println("我是可聚焦的")
}

class Button : Shape(), Clickable, Focusable {
    override fun area() = 0.0
    override fun click() = println("点击")

    // 两个接口都有 showOff，必须显式消歧义
    override fun showOff() {
        super<Clickable>.showOff()
        super<Focusable>.showOff()
    }
}

要点：

  • 接口可以有默认实现，也可以有属性（但属性不能有 backing field，只能抽象或提供 getter）；
  • 一个类只能继承一个父类，但可以实现多个接口；
  • 抽象类可以有构造函数和状态，接口不能。

可见性修饰符

修饰符 说明
public 默认，到处可见
private 类内 / 文件内可见
protected 类及子类可见（接口中不可用）
internal 同一模块（同一个 Gradle module）内可见 
class Account {
    private var balance = 0
    internal fun audit() = println("audit: $balance")
    protected open fun hook() {}
}

数据类（data class）

data class Point(val x: Int, val y: Int)

val p1 = Point(1, 2)
val p2 = Point(1, 2)

println(p1)                    // Point(x=1, y=2) —— 自动 toString
println(p1 == p2)              // true —— 自动 equals/hashCode
println(p1.copy(y = 5))        // Point(x=1, y=5) —— 自动 copy
val (x, y) = p1                // 自动 componentN，支持解构
println("$x, $y")

data class 的要求：

  • 主构造函数至少有一个参数，且参数必须标 val/var；
  • 不能是 abstract、open、sealed；
  • equals/hashCode/toString/copy/componentN 只基于主构造函数中的属性——这一点常被误解。

枚举类（enum class）

enum class Color(val hex: String) {
    RED("#FF0000"),
    GREEN("#00FF00"),
    BLUE("#0000FF");                    // 有成员时，最后一项后要加分号

    fun describe() = "$name = $hex"
}

println(Color.RED.describe())
println(Color.valueOf("GREEN").ordinal)     // 1
println(Color.entries.map { it.name })      // [RED, GREEN, BLUE]

密封类 / 密封接口（sealed）

用于表达「有限且已知的几种情况」，配合 when 可以做到穷尽性检查：

sealed class Shape {
    data class Circle(val radius: Double) : Shape()
    data class Rect(val w: Double, val h: Double) : Shape()
    data object Point : Shape()
}

fun area(shape: Shape): Double = when (shape) {   // 不需要 else，编译器检查是否覆盖全部
    is Shape.Circle -> Math.PI * shape.radius * shape.radius
    is Shape.Rect -> shape.w * shape.h
    Shape.Point -> 0.0
}

委托

类委托——把接口实现交给另一个对象：

interface Printer { fun print(msg: String) }

class ConsolePrinter : Printer {
    override fun print(msg: String) = println(msg)
}

class LoggingPrinter(private val inner: Printer) : Printer by inner {
    override fun print(msg: String) {
        println("[log] 即将打印")
        inner.print(msg)      // 也可以不覆写，直接沿用 inner 的实现
    }
}

创建与可变性

val nums = listOf(1, 2, 3, 4, 5, 6)

people.associateBy { it.n }              // {Tom=P(Tom,20), Ann=P(Ann,18)}

序列（Sequence）：惰性求值

链式调用会为每一步创建中间集合。数据量大时用 asSequence() 改成惰性求值，只遍历一次：

val result = (1..1_000_000)
    .asSequence()
    .filter { it % 3 == 0 }
    .map { it * 2 }
    .take(5)
    .toList()

println(result)   // [6, 12, 18, 24, 30]，且只计算了必要元素

判断标准：小集合用 List（更快、更直观），大集合或需要短路时用 Sequence。

作用域函数

let、run、with、apply、also 的区别只有两点：接收者怎么引用（it 还是 this）、返回什么。

函数 接收者 返回值 典型场景
let it lambda 结果 空值检查、局部变量重命名
run this lambda 结果 计算一个值、需要访问多个成员
with this lambda 结果 对同一对象做多次操作（非扩展函数）
apply this 接收者本身 对象配置/初始化
also it 接收者本身 副作用：日志、校验 
// let：安全调用
val name: String? = "Kotlin"
name?.let { println("长度 ${it.length}") }

// run：把多步计算包成一个表达式
val result = run {
    val a = 10
    val b = 20
    a + b
}

// with：连续操作同一对象
with(StringBuilder()) {
    append("Hello")
    append(", ")
    append("World")
    println(toString())
}

// apply：配置对象并返回它本身
data class Request(var url: String = "", var method: String = "GET")

val req = Request().apply {
    url = "https://example.com"
    method = "POST"
}
println(req)   // Request(url=https://example.com, method=POST)

// also：不改变链式结构地插入副作用
val list = mutableListOf(3, 1, 2)
    .also { println("排序前: $it") }
    .apply { sort() }
    .also { println("排序后: $it") }

记忆窍门：apply / also 返回「自己」，区别在 apply 用 this（适合配置）、also 用 it（适合打印）； let / run 返回「结果」，区别同上。

型变：out 与 in

Kotlin 用声明处型变，比 Java 的通配符更简洁：

// out T：只生产（返回）T —— 协变，List<String> 可赋给 List<Any>
interface Producer<out T> { fun produce(): T }

// in T：只消费（接收）T —— 逆变，Comparable<Any> 可赋给 Comparable<String>
interface Consumer<in T> { fun consume(item: T) }

标准库中 List<out E> 是协变的，MutableList<E> 是不变的，Comparable<in T> 是逆变的。

异常处理

Kotlin 没有受检异常（checked exception），不需要在方法签名上写 throws：

fun parse(s: String): Int {
    return try {
        s.toInt()
    } catch (e: NumberFormatException) {
        println("解析失败: ${e.message}")
        -1
    } finally {
        println("无论成功失败都会执行")
    }
}

try 也是表达式，可以直接赋值：

val n = try { "12".toInt() } catch (e: Exception) { 0 }

自定义异常与 throw：

class ValidationException(message: String) : Exception(message)

    if (age < 0) throw ValidationException("年龄非法: $age")
}

推荐用 runCatching 把异常转成结果值（避免用异常控制流程）：

val result: Result<Int> = runCatching { "abc".toInt() }

result
    .onSuccess { println("成功: $it") }
    .onFailure { println("失败: ${it.message}") }

协程

协程用一个词概括：可以用同步的写法写异步代码，而且能挂起而不阻塞线程。

添加依赖

dependencies {
    implementation("org.jetbrains.kotlinx:kotlinx-coroutines-core:1.9.0")
}

如果只写单文件脚本，用 Gradle 或 IDEA 项目；kotlin script 直接跑需要 classpath 上有协程库。

suspend 函数

suspend 标记的函数只能在协程（或另一个 suspend 函数）中调用：

suspend fun fetchUser(id: Int): String {
    delay(1000)              // 挂起 1 秒，不阻塞线程（对比 Thread.sleep）
    return "user-$id"
}

runBlocking / launch / async

import kotlinx.coroutines.*

fun main() = runBlocking {          // 桥接阻塞世界与协程世界，仅用于 main 或测试
    val job: Job = launch {         // 启动一个不返回结果的协程
        println("子协程开始")
        delay(500)
        println("子协程结束")
    }
    println("主协程继续执行")
    job.join()                      // 等待子协程完成
}
suspend fun fetchA(): String { delay(500); return "A" }
suspend fun fetchB(): String { delay(500); return "B" }

fun main() = runBlocking {
    val start = System.currentTimeMillis()

    val result = coroutineScope {
        val a = async { fetchA() }     // Deferred<String>，立即开始
        val b = async { fetchB() }     // 并发执行
        a.await() + b.await()          // 都完成后拼接
    }

    println("结果 = $result，耗时 ${System.currentTimeMillis() - start} ms")
    // 约 500ms，而不是 1000ms
}

调度器与 withContext

调度器 用途
Dispatchers.Default CPU 密集计算（默认，线程数 = CPU 核数）
Dispatchers.IO 阻塞式 IO（文件、网络、数据库），线程池更大
Dispatchers.Main UI 线程（Android/JavaFX，需额外依赖）
Dispatchers.Unconfined 不切换线程，特殊场景使用 
suspend fun loadData(): String = withContext(Dispatchers.IO) {
    // 这里可以安全调用阻塞 API（读文件、JDBC 等）
    java.io.File("/tmp/data.txt").readText()
}

withContext 会切换线程并在结束后切回，是「进入不同上下文执行一段代码」的标准手段。

结构化并发与作用域

协程必须运行在 CoroutineScope 里。作用域会跟踪所有子协程，父作用域结束前会等待子协程（或取消它们）。这解决了「协程泄漏」。

class MyViewModel {
    private val scope = CoroutineScope(Dispatchers.Default + SupervisorJob())

    fun load() {
        scope.launch {
            val data = fetchA()
            println(data)
        }
    }

    fun clear() {
        scope.cancel()     // 取消所有子协程，防止内存泄漏
    }
}

常用的作用域构建器：

构建器 特点
coroutineScope { } 子协程失败 → 全部取消，并抛出异常；等待全部完成
supervisorScope { } 一个子协程失败不影响兄弟协程
runBlocking { } 阻塞当前线程直到内部完成（测试/main 用）
GlobalScope 全局作用域，不推荐（无法取消、易泄漏）

取消

协程取消是协作式的：必须检查取消状态。挂起函数（delay、await 等）会自动检查，纯计算代码要手动检查：

val job = launch {
    repeat(1000) { i ->
        ensureActive()          // 或 yield()，或 isActive 判断
        // 纯计算...
    }
}

delay(100)
job.cancelAndJoin()             // 取消并等待结束

finally 里可以做清理，但不能再调用挂起函数（除非用 withContext(NonCancellable)）：

try {
    // 工作
} finally {
    withContext(NonCancellable) {
        // 这里仍可挂起，用于释放资源
    }
}

异常处理

  • launch 的异常会向父作用域传播，可以用 CoroutineExceptionHandler 兜底；
  • async 的异常在 await() 时抛出；
import kotlinx.coroutines.*

fun main() = runBlocking {
    val handler = CoroutineExceptionHandler { _, e ->
        println("捕获到异常: ${e.message}")
    }

    val job = launch(handler) {
        throw RuntimeException("出错了")
    }
    job.join()

    // async 的异常在 await() 时才抛出
    // 用 supervisorScope 隔离，避免失败的子协程把 runBlocking 也取消掉
    supervisorScope {
        val deferred = async { throw IllegalStateException("async 失败") }
        runCatching { deferred.await() }
            .onFailure { println("await 捕获: ${it.message}") }
    }
}

不要让异常静默吞掉：supervisorScope 里的子协程需要各自 try/catch，否则异常会被丢弃。

Flow：冷数据流

Flow 用于表示「随时间产生多个值」的异步序列，类似 RxJava，但更轻量、与协程原生集成。

import kotlinx.coroutines.*
import kotlinx.coroutines.flow.*

fun countdown(): Flow<Int> = flow {          // 冷流：每次 collect 都重新执行
    for (i in 3 downTo 1) {
        delay(300)
        emit(i)
    }
}

suspend fun main() {
    countdown()
        .filter { it > 1 }
        .map { it * 10 }
        .onEach { println("收到 $it") }
        .collect { println("处理 $it") }

    // 其他终端操作
    val list: List<Int> = countdown().toList()
    val first: Int = countdown().first()
}

常用组合：map / filter / take / onEach / catch / debounce / combine / zip / flatMapMerge。 切换上游执行线程用 flowOn(Dispatchers.IO)（注意：flowOn 只影响它上游的代码）。

常见坑与最佳实践

常见坑

  1. 整数除法：5 / 2 == 2，要小数请写 5.0 / 2 或 5.toDouble() / 2。
  2. val 不等于不可变：val list = mutableListOf(1) 仍然可以 list.add(2)，只是不能再指向别的对象。
  3. listOf 不是绝对不可变：不要 as MutableList，需要可变请用 mutableListOf 或 toMutableList()。
  4. data class 的 equals 只看主构造属性：body 里的属性不参与比较。
  5. == 与 ===：== 比内容（调用 equals），=== 比引用。
  6. !! 滥用：遇到可空类型先想 ?: / ?.let / 提前 return，而不是直接 !!。
  7. Array<Int> 与 IntArray 不同：前者是装箱对象数组，后者是原始类型数组；Array(3){0} vs IntArray(3)。
  8. 浮点精度：0.1 + 0.2 != 0.3；涉及金额用 BigDecimal 或整数分。
  9. lateinit 与基本类型：lateinit var x: Int 不合法，用 Delegates.notNull<Int>()。
  10. 协程里用 Thread.sleep：会阻塞线程，应改为 delay。
  11. GlobalScope：无法取消、无法追踪，一律用自定义 CoroutineScope。
  12. when 不穷尽：对 sealed 类型不要写无意义的 else，否则新增子类时编译器无法提醒你。
  13. sortedBy 每次调用都会创建新列表：注意别在循环里重复排序。
  14. 扩展函数不会被多态覆盖：调用哪个版本取决于声明的静态类型。
  15. internal 只在模块内有效：跨模块使用会编译失败，别拿它当「包私有」用。

编码习惯

  • 默认 val，默认不可变集合（listOf），只有需要修改时才用可变版本。
  • 用 data class 表达数据，用 sealed 表达状态，用 enum 表达固定选项。
  • 公共 API 显式写返回类型（避免推断结果意外变化）。
  • 用 require / check 做前置断言，让错误尽早暴露。
  • 集合链式操作不超过 4~5 步，再长就抽成命名函数。
  • 命名遵循官方风格：类 PascalCase，函数/属性 camelCase，常量 UPPER_SNAKE_CASE。
  • 字符串拼接优先用模板 "$a-$b"，多行内容用 trimIndent()。

练习 2：空安全

给定 data class User(val name: String, val email: String?)，写函数返回「邮箱域名」，没有邮箱时返回 "unknown"。

参考答案 
fun domainOf(user: User?): String =
    user?.email?.substringAfter('@', missingDelimiterValue = "")?.ifBlank { "unknown" } ?: "unknown"

// 更清晰的写法
fun domainOf2(user: User?): String {
    val email = user?.email ?: return "unknown"
    return email.substringAfter('@', "unknown")
}

练习 3：密封类 + when

定义 sealed class Expr，包含 Num、Add、Mul，写出求值函数。

参考答案 
sealed class Expr {
    data class Num(val v: Double) : Expr()
    data class Add(val a: Expr, val b: Expr) : Expr()
    data class Mul(val a: Expr, val b: Expr) : Expr()
}

fun eval(e: Expr): Double = when (e) {
    is Expr.Num -> e.v
    is Expr.Add -> eval(e.a) + eval(e.b)
    is Expr.Mul -> eval(e.a) * eval(e.b)
}

println(eval(Expr.Add(Expr.Num(1.0), Expr.Mul(Expr.Num(2.0), Expr.Num(3.0)))))  // 7.0

练习 4：协程

并发请求两个接口（各耗时 1 秒），总耗时控制在 1.1 秒以内，并处理其中一个失败的情况。

参考答案 
import kotlinx.coroutines.*
import kotlin.system.measureTimeMillis

suspend fun callApi(name: String, fail: Boolean = false): String {
    delay(1000)
    if (fail) throw RuntimeException("$name 请求失败")
    return "$name-ok"
}

fun main() = runBlocking {
    val elapsed = measureTimeMillis {
        supervisorScope {
            val a = async { runCatching { callApi("A") } }
            val b = async { runCatching { callApi("B", fail = true) } }

            val ra = a.await()
            val rb = b.await()

            println("A: ${ra.getOrNull() ?: ra.exceptionOrNull()?.message}")
            println("B: ${rb.getOrNull() ?: rb.exceptionOrNull()?.message}")
        }
    }
    println("耗时 $elapsed ms")
}

要点：并发用 async + await；互不影响用 supervisorScope + 各自 runCatching。
