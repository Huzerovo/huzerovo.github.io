Git 提交规范

发布日期: 2023-11-02更新日期: 2023-12-31

记录一下我自己的 commit 注释规范

前言

仅仅用于自己的一些比较大的项目，或者说提交量比较多的项目中， 尽可能遵守这里记录的提交风格，不然我自己都看不懂提交了些啥玩意。

博客文章提交

基本格式：<type>(type, type): <msg>。其中的type为以下类型：

类型意义
draft创建新的草稿
post创建新文章
corr文章错误更正
theme主题更新
config配置更新
update文章内容更新
others其他操作

<type>表示此次提交的主要操作，(type)表示此次提交中还进行其他附加操作。 <msg>描述主要操作都干了啥， 对于其他操作应该有比较详细的描述， 对于附加操作可以不说明。

自己项目的代码提交

基本格式：<type>: <msg>。

类型意义
feat新功能实现
fix缺陷修复
typo错别字更正
revert版本回退
style代码风格变更
refact代码重构
docs修改注释
merge代码合并
others其他操作
