Learn Markdown

发布日期: 2020-11-08更新日期: 2023-07-20

Markdown 学习笔记，更新后算是个人习惯写法，使用hexo-randerer-markdown-it渲染。

注意，使用markdown-it作为渲染 引擎，因此部分语法可能略有差异。

好习惯

在每个不同的 Markdown 文本块^Markdown 文本块之间使用空行或许是个好习惯。

标题

用不同数量的#标记，一个#表示一级标题，两个表示二级，以此类推。 一般使用这个方法。

# 一级标题

## 二级标题

### 三级标题

#### 四级标题

##### 五级标题

###### 六级标题

使用---或者===会识别将上一行为一级标题。由于好习惯， 我并不推荐使用这种方式。 个人习惯是在标题的上下都添加一个空行。 此外---还能用作分隔线。

段落

在段落之间添加一个空行，另外，在行尾添加空格， 下一行也会被识别为新的段落，因此需要注意避免在行尾留后空格。

这是一个段落

这是另一个段落

粗体与斜体

使用*可将一段文字标注为粗体或者斜体。

*斜体*
*斜体*

**粗体**
**粗体**

***斜粗体***
***斜粗体***

注意_也能够用于以上目的，且可与*混用。 但考虑到在一般的写作中_比*常用，因此我不推荐使用。

分隔线

我一般使用-作为分割线。

---

_与*也能够用于以上目的，由于_在一般的写作中比较常用，*用于字体样式， 因此推荐使用-。需要注意的是，-会将上一行作为空行， 因此使用空行是一个好习惯

也可以~~行内~~使用。

代码

行内代码

在段落上嵌入的代码，用反引号包裹代码。

C 语言入口函数：`main()`

代码块

一段代码可以使用三个反引号包裹代码段，可以在前三个反引号后指定代码语言， 这里由于渲染原因，使用'代替例子中的反引号。

'''c
#include <stdio.h>
int main()
{
  printf("Hello world");
  return 0;
}
'''

还有一个不推荐的方法：使用空格或者制表符（TAB 键）缩进。

嵌套

大部分 Markdown 文本块^Markdown 文本块都能够相互嵌套。 但在 Markdown 代码块中不能嵌套另一个代码块， 这也是在代码块中使用'代替的原因。

链接

[链接名字](链接地址)或者<链接地址>

<https://huzerovo.github.io\>

表格

用 | 划分列 用 - 划分表头和其他行

可以设置对其方式： -: 整列右对齐 :- 整列左对齐 :-: 整列居中对齐

| 表头 1 | 表头 2 | 表头 3 |
| :---- | ----: | :---: |
| 靠左  |  靠右 | 居中  |
| 列 1   |   列 2 |  列 3  |
