01 · 构建流程（build pipeline）

入口：build(options) in src/build.ts。返回 BuildResult { config, site, pages }。

主流程（含 hook）

flowchart TD
  start([build options]) --> cfg["loadSiteConfig(cwd)"]
  cfg --> lt["loadTheme(theme, cwd)<br/>resolveThemeDir → esbuild bundle → import<br/>+ loadThemeConfig 合并 theme.config"]
  lt --> dev{"options.dev?"}
  dev -->|yes| rd["siteConfig.renderDraft = true"]
  dev -->|no| sit
  rd --> sit["new SiteImpl(siteConfig)"]
  sit --> cp["initCorePlugins(site, cwd)<br/>HelperRegistryImpl(site) + registerCoreHelpers<br/>Generator/Renderer/Hooks + scoped API + registerCoreGenerators"]
  cp --> ltp["loadThemePlugins(scoped) → loadPlugins(themes/theme/plugins)"]
  ltp --> lsp["loadSitePlugins(scoped) → loadPlugins(pluginsDir)"]
  lsp --> cca["new CoreApiImpl(cwd, site, theme, helpers)"]
  cca --> h1(["hook: afterInit(site)"])
  h1 --> read["seqRead(contentRoot, cwd) → FileEntry[]"]
  read --> h2(["hook: afterRead(files)"])
  h2 --> parse["seqParse(siteConfig, contentRoot, files) → Page[]"]
  parse --> h3(["hook: afterParse(physicsPage)"])
  h3 --> filter["filter: 非 dev 剔除 draft → filteredPages"]
  filter --> h4(["hook: afterFilter(filteredPages)"])
  h4 --> c1["seqCollect(siteConfig, filteredPages) → Collection[]<br/>写入 site.collections"]
  c1 --> h5(["hook: afterCollectPhysical(collections)"])
  h5 --> gen["seqGenerate(site, callbacks) → virtualPages<br/>逐个 await generator"]
  gen --> h6(["hook: afterGenerate(virtualPages)"])
  h6 --> merge["allPages = filteredPages + virtualPages<br/>checkUrlConflicts(allPages)"]
  merge --> h7(["hook: afterMerge(allPages)"])
  h7 --> c2["collectVirtual(site.collections, virtualPages)"]
  c2 --> h8(["hook: afterCollectVirtual(collections)"])
  h8 --> proc["process:<br/>scanAssets(...) → site.assets<br/>+ 主题 assets（less 编译）"]
  proc --> h9(["hook: afterProcess(assets)"])
  h9 --> render["render loop（逐页）"]
  render --> h10(["hooks: beforeRender / afterRender"])
  h10 --> write["seqWrite(distDir, results, assets)<br/>+ copy public/"]
  write --> h11(["hooks: beforeWrite / afterWrite"])
  h11 --> done([BuildResult])

阶段明细

#阶段实现输入 → 输出触发 hook
0配置loadSiteConfig（config.ts）cwd → SiteConfig—
0主题loadTheme（theme/index.ts）themeName → { theme, themePath }—
0APIinitCorePlugins + loadThemePlugins/loadSitePlugins + new CoreApiImpl（均在 build.ts 内直调）site → CoreAPI—
0初始化完成build.tssiteafterInit
1readseqRead（sequence/read.ts）contentRoot → FileEntry[]afterRead
2parseseqParse（sequence/parse.ts）files → Page[]（物理页）afterParse
3filterbuild.ts 内联物理页 → filteredPages（去 draft）afterFilter
4collect①(物理)seqCollect（sequence/collect.ts）filteredPages → Collection[] → site.collectionsafterCollectPhysical
5generateseqGenerate（sequence/generate.ts）site + callbacks → virtualPagesafterGenerate
6mergebuild.ts 内联filtered + virtual → allPages + URL 冲突检测afterMerge
7collect②(虚拟)collectVirtual（sequence/collect.ts）site.collections + virtualPagesafterCollectVirtual
8processscanAssets（assets.ts）+ 主题资源allPages → site.assetsafterProcess
9renderrenderers.get('markdown') + renderPage（theme/render.ts）逐 page → RenderResult{ page, html }beforeRender / afterRender
10writeseqWrite（sequence/write.ts）+ copyDir(public)results + assets → dist/beforeWrite / afterWrite

Hook 时序

sequenceDiagram
  participant B as build()
  participant H as Hooks
  participant P as Plugins
  B->>H: afterInit(site)
  B->>H: afterRead(files)
  B->>H: afterParse(physicsPage)
  B->>H: afterFilter(filteredPages)
  B->>H: afterCollectPhysical(collections)
  B->>H: afterGenerate(virtualPages)
  B->>H: afterMerge(allPages)
  B->>H: afterCollectVirtual(collections)
  B->>H: afterProcess(assets)
  loop 每个 page
    B->>H: beforeRender(page)
    B->>H: afterRender(page)
  end
  B->>H: beforeWrite(pages, assets)
  B->>H: afterWrite()
  Note over H,P: 插件在加载时经 api.hook.*.tap(name, fn) 注册

Hook 实现：AsyncHookImpl（src/plugins/hook.ts），按注册顺序串行 await。定义见 src/types/hook.ts。 仅 beforeRender / beforeWrite 是「前置」钩子，其余为各阶段结束后的 afterX。

关键设计点

  • 两段 collect：collect① 在 generate 前把物理页分组为集合（generators 经 site 使用，如 site.collections.get(...) / site.posts）；collect② 在 generate 后把虚拟页挂入集合（不存在则动态创建，如 core:virtual），保证 site.pages 完整。
  • generator 入参为 site（GeneratorCallback = (site: Site) => Page[]），内置以 core: 前缀命名（core:home/core:archives/core:taxonomy）。
  • renderer 按名取用：renderers.get('markdown')，内置默认在 initCorePlugins 注册。
  • 调试落盘：dumpMiddle() 会把各阶段产物写入 process.cwd()/buildMid/*.json（调试用，注意生产环境会污染工作目录）。
