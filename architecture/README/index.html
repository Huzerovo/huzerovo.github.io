一句话概览

@hulog/core 把「Markdown 内容 + 站点配置 + 主题」编译为静态站点：build() 按固定阶段流水线运行，每个阶段由 src/sequence/* 的 seqXxx 函数实现，阶段边界触发 Hooks；plugins/ 按前缀注入作用域化插件 API 并产出内部 Registries；core-api.ts 聚合出主题可见的 CoreAPI（site / theme / helper）。

快速事实

  • 入口：src/index.ts → build()（src/build.ts）
  • 管线：init → read → parse → filter → collect①(物理) → generate → merge → collect②(虚拟) → process → render → write
  • 主题：themes/<name>/index.ts 导出 Theme 对象；esbuild bundle 为 ESM 后 import
  • 插件：按文件名前缀自动发现（generator- / hook- / renderer- / helper-）
  • 统一 API：CoreAPI { root, site, theme, plugins }；主题 LayoutProps = { page, api }
  • 构建命令：npm run build（core+cli）、npm run test（core 单测）、npm run typecheck
