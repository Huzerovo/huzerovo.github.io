阶段间数据流转

flowchart LR
  content["content/ 目录<br/>Markdown + 资源"] --> read
  read["read<br/>seqRead"] -->|"FileEntry[]"| parse
  parse["parse<br/>seqParse"] -->|"Page[]（物理页）"| filter
  filter["filter<br/>去 draft"] -->|"filteredPages"| c1
  c1["collect①<br/>seqCollect"] -->|"Collection[]"| siteCols["site.collections"]
  c1 --> gen
  gen["generate<br/>seqGenerate"] -->|"virtualPages"| merge
  filter --> merge
  merge["merge<br/>allPages"] -->|"Page[]"| proc
  merge --> c2["collect②<br/>collectVirtual"]
  c2 --> siteCols

  render["render<br/>renderer + renderPage"] -->|"RenderResult[]"| write

classDiagram
  class Page {
    +id: string
    +url: string

  Site "1" o-- "many" Collection
  Collection "1" o-- "many" Page
  Site "1" o-- "many" Asset
  RenderResult --> Page
  • Page = PageBase & Partial<PagePostOptional> & PageOptional（types/page.ts）。
  • 虚拟页集合常量：VIRTUAL_PAGE_COLLECTION = "core:virtual"；front-matter 保留键 RESERVED_KEYS。
  • Site.posts：从 posts（renderDraft 时叠加 drafts）聚合；Site.pages 为所有集合扁平化。

配置数据与优先级

flowchart TD
  subgraph site["站点配置"]
    sd["loadSiteConfig defaults"] --> sc["SiteConfig"]
    bc["blog.config.*"] --> sc
  end
  subgraph theme["主题配置"]
    td["theme.config 默认（Theme.config）"] --> tc["theme.config"]
    tcf["theme.config.*"] --> tc
  end
  sc --> api1["api.site.config"]
  tc --> api2["api.theme.config"]
  sc -. themeAssetsMode/theme .-> helper["themeAsset helper"]
  • 站点配置：loadSiteConfig 先内置 defaults，再 ...result.config 覆盖（contentDir / assetsDir / pluginsDir / archivesDir / paginationDir / perPage / themeAssetsMode / renderDraft …）。
  • 主题配置：loadTheme 内 theme.config = { ...theme.config, ...loadThemeConfig(cwd) }，经 api.theme.config 访问。
  • 站点配置与主题配置分离（SiteConfig 不再含 themeConfig）。

URL 生成规则

flowchart LR
  permalink["front-matter permalink"] -->|最高| u["Page.url"]
  route["collection.routePattern"] -->|次之| u
  fs["文件系统默认映射<br/>index.md → 父目录"] -->|兜底| u
  u --> conflict["merge: checkUrlConflicts<br/>（去尾斜杠归一化比较）"]
  • resolveUrl（route.ts）支持占位符 :slug :collection :year :month :day。
  • 虚拟页（core:virtual）URL 在 generate 阶段补尾斜杠 /（seqGenerate），便于输出为 index.html。
