GFM 语法示例

GFM 语法示例

GitHub Flavored Markdown（GFM）是 GitHub 在 CommonMark 基础上的方言，本文依据官方规范逐节整理示例，同时用于本站渲染管线（unified + remark-gfm）的验收。

GFM = CommonMark 超集 + 六项扩展：表格、任务列表、删除线、自动链接（裸 URL / 邮箱）、脚注、禁用原始 HTML（tagfilter）。

段落与换行

段落之间用空行分隔；相邻的文本行会合并为一个段落（软换行）。

行尾加两个空格或一个反斜杠可以强制换行（硬换行），源码如下：

第一行  
第二行（行尾两个空格，硬换行）
第三行\
第四行（行尾反斜杠，硬换行）

实际渲染效果：

第一行
第二行（行尾两个空格，硬换行） 第三行
第四行（行尾反斜杠，硬换行）

强调与加粗

语法效果
*斜体*斜体
_斜体_斜体
**加粗**加粗
__加粗__加粗
***斜粗体***斜粗体
**加粗与*斜体*嵌套**加粗与斜体嵌套

分隔符规则：* 与 _ 均可，但同一处不能混用（*_foo_* 不是强调）；单词中间的下划线不会触发强调，例如 foo_bar_baz 保持原样。

删除线（扩展）

用一对 ~~ 包裹：删除线，用于表示已废弃、已修正的内容。

行内代码

用反引号包裹：行内 code 中的 *、_、[ 等特殊字符不会被解析。

需要显示反引号本身时，用更多反引号包裹：`code`；单个反引号字符：`。

代码块

围栏代码块：三个及以上反引号或波浪线，可标注语言（本博客用 shiki 高亮）：

interface Post {
  title: string;
  tags: string[];
  toc?: boolean;
}

链接

行内链接：[文字](https://example.com "标题") → 示例链接

带强调的链接：加粗链接 与 代码链接。

引用式链接：先使用 [文字][引用名]，文末定义 [引用名]: URL "可选标题"。

引用式链接 与 快捷引用式链接（引用名与文字相同）。

自动链接

尖括号自动链接（CommonMark）：https://github.github.com/gfm/ 与 mailto:hello@example.com。

扩展自动链接（GFM）：裸 URL、www 开头域名与裸邮箱在文本中自动识别：

  • 访问 https://example.com 即可。
  • 官网 www.example.com 欢迎你。
  • 联系 test@example.com。

注意：自动链接对前导字符有要求（www. 前需为空白或标点），例如 前缀www.example.com 不会自动链接——这是规范行为。

转义字符与实体引用

反斜杠转义：\ 可转义 Markdown 特殊字符。

*不是强调*，_也不是_，# 不是标题，` 不是代码。

实体引用：&copy; → ©，&#35; → #，&amp; → &。
